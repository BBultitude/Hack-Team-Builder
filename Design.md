# Hack Team Builder: build specification

## 1. Purpose
Mobile-first static web app helping a player of GBA Pokémon ROM hacks (Unbound, Emerald Rogue, etc.) build a balanced team from Pokémon they own, and pick the best party member against an opponent. It uses vanilla (unmodified official game) data for Generations (Gen) 1–9 as a baseline, plus a per-hack data pack (Unbound, Emerald Rogue) built from each hack's own open sources. Anything else is handled by manual edits.

## 2. Decisions already made
- Vanilla data plus optional hack packs (section 3); user edits types, ability, moves and base stats per Pokémon.
- Moves: "level B" (known moves plus learnable-move suggestions). The Opponent tab estimates damage with the Gen 3+ formula; it is not a full calculator (section 7).
- Opponent tab is simple: best member, worst member, plain-English reasons.
- Define every acronym once (STAB = Same-Type Attack Bonus: 1.5× damage when a move's type matches the user's type). Use full stat names (Attack, Special Attack, Speed).
- Australian English. Concise professional tone.
- Deployed as one Docker container: a dependency-free Node server serves the built site and the sync API. No requests to outside hosts at runtime (sprites and fonts are self-hosted).
- One **game setup** per game played, each with its own roster, team and opponent, capped at "Pokémon up to and including Gen N". The game's rules follow the cap (section 5).
- Visual identity: the Gen 1 anime Pokédex in full colour (red shell, blue lens as the sync light, three small lights), laid out as a field tool for glancing at beside an emulator.

## 3. Data (build-time pipeline)
Source: PokeAPI CSVs (github.com/PokeAPI/pokeapi, data/v2/csv): pokemon, pokemon_types, pokemon_stats, pokemon_abilities, abilities, moves, pokemon_moves.
- Species: ids ≤ 1025 plus alternate forms (Mega, regional) only where types differ from the base species; exclude Gigantamax; skip entries with no types.
- Per entry: name, 1–2 types, 6 base stats (Hit Points, Attack, Defense, Special Attack, Special Defense, Speed), abilities (flag hidden).
- Moves: damaging only (damage class physical/special, id < 10000), including power 0/variable. 648 moves with name, type, power.
- Learnsets: union of all version groups per species; forms without their own moves reference the base species. `learngens.json` holds, per entry, the first generation it was learnable in, so a setup can drop moves only later games teach.
- Generations: each entry has `g` (species generation, or the form's own debut: Megas Gen 6, Alolan forms Gen 7), `pt` (pre-Gen 6 types from pokemon_types_past) and `pa` (past ability slots from pokemon_abilities_past). Moves have `g`. `catchgens.json` gives the first generation each catch-helper learner could learn the move.
- Plus 18 pseudo-moves "Any [Type] move" (power 80) for hacks that retype or rename moves.
- Type chart: 18 types including Fairy. Type order: Normal, Fire, Water, Electric, Grass, Ice, Fighting, Poison, Ground, Flying, Psychic, Bug, Rock, Ghost, Dragon, Dark, Steel, Fairy.
- 25 natures: +10% to one stat, −10% to another, or neutral.
**Hack packs** (`npm run build:hacks`, `scripts/build-hacks.ts` → `data/hacks/<hack>.json`): the upstream community sources romhackdex.net credits, fetched at pinned commits. Nothing is taken from romhackdex itself (its terms bar reproducing the site).
- Unbound: species, types, stats, abilities and level-up moves from Skeli789/Dynamic-Pokemon-Expansion (Unbound branch, WTFPL); boss teams per difficulty (level, ability, item, nature, EVs, IVs, moves, party order) from Owakeningowl/unbound-calc's set files, parsed as text and never run. All four difficulties are listed in game order; Vanilla uses the Difficult teams, as the calc does (it has no Vanilla file; Vanilla swaps a few moves and lowers levels). The regional dex order comes from DPE's `gPokedexOrder_Regional`, catch rates from `Base_Stats.c`, and where to find each species from nMckenryan/Borrius-Pokedex-Scraper's `pokelocation.json` (964 entries).
- Emerald Rogue: species from Pokabbie/pokeemerald-rogue EX-v2.1 (`#if` blocks resolved to their newer branch). It currently matches vanilla Gen 9 exactly; trainers are randomised, so there are no boss teams.
- A pack holds only differences, keyed by name: changed species, forms the vanilla dex lacks (Megas, Therian, Kyurem-Black: appended with the base's sprite), extra level-up moves, trainers, and an `unmatched` list. The build fails if over 2% of species don't map.
- Prototype size is about 165 KB (about 1,133 entries). In a real app, ship as JSON files, versioned, generated by a script that is re-runnable.

## 4. Storage and sync
Roster entry: { n: name, a: type1, b: type2 or -1, ab: ability, nt: nature index, mv: [4 move names], st: 6 stat overrides or null, d: dex index or -1 (custom Pokémon), lv: level 1–100 (absent in old saves, read as 50) }
Per setup, also: team (indices, max 6), opponent {name, ability, and optionally lv, mv, item, nt, ev, iv, trainer}, rank scope ("team" or "all").
- Browser: `ptb2:setups` = { active, list: [{ id, name, gen, hack?, difficulty?, updatedAt, deleted?, fresh? }] }; each setup's state under `ptb2:s:<id>`. A pre-setups save under `ptb2` migrates into "My game" (Gen 9). Every change is saved locally first, so the app never waits on the network.
- Server (`server/index.mjs`): `GET /api/setups`, `GET|PUT|DELETE /api/setups/:id`, `GET /api/health`. One JSON file per setup in `DATA_DIR`, written via temp file + rename. Ids match `^[a-z0-9-]{1,40}$`; bodies capped at 512 KB; fields type-checked; optional `ACCESS_CODE` bearer token. The app re-validates every roster entry on load.
- Sync: on start, on focus, and 1 s after a change. Newest `updatedAt` wins per setup (409 hands an older writer the newer copy). Deletes are tombstones. A new device's untouched automatic "My game" is dropped when the server already has games.

## 5. Features and logic
**Pokédex tab:** the game's dex as a checklist: the hack's regional dex (with a National toggle) or the National Dex up to the cap, without battle-only forms (Mega, Primal, Gigantamax). Ticked means owned; ticking adds it (joining the team while there's room), unticking removes the newest one, and one with edits needs a second untick. Evolving swaps the species in place, so the tick moves with it. Filter by name, All / Caught / Missing, a caught counter. Custom Pokémon and anything owned outside the list sit under "Other Pokémon".
**Pokémon modal:** tapping an owned Pokémon (checklist row, party slot, Best Team grid number) opens a native dialog over any tab: team toggle, matchups as type chips (Weak to, Resists, Immune to, Hits hard), and the editor below.
**Per-Pokémon edit:** ability, level, nature, 4 moves (any move allowed, with a note if not in the vanilla learnset), 6 base stats (marked "modified from vanilla" with a reset button).
**Effective stat:** base × 1.1 or 0.9 for nature. Role: Physical if Attack > Special Attack × 1.15, Special if the reverse, else Mixed.
**Ability effects modelled:**
- Immunities: Levitate, Earth Eater (Ground); Flash Fire, Well Baked Body (Fire); Water Absorb, Storm Drain, Dry Skin (Water); Volt Absorb, Lightning Rod, Motor Drive (Electric); Sap Sipper (Grass).
- Halve: Thick Fat (Fire, Ice); Heatproof, Water Bubble (Fire); Purifying Salt (Ghost).
- Wonder Guard: only super-effective hits land.
- Filter, Solid Rock, Prism Armor: ×0.75 on super-effective hits.
- Attacker-side abilities (Mold Breaker, etc.) are not modelled.
**Team analysis (up to 6):**
- Defence first, as on the Opponent tab: a team that isn't one-shot beats one that hits everything.
- Type grid, one table with a Takes / Hits toggle. Takes: for each attack type in play (18, or 17 before Gen 6), each member's multiplier (ability applied), with a Team column of weak / resist counts. Hits: each member's best multiplier into a Pokémon of that type, with the team's best (red "none" when nobody beats ×1). Blue is good for you and red bad in both views.
- Per member and type multiplier x: x ≥ 3 → weak +2, score −3; x > 1 → weak +1, −1; x = 0 → resist +1, +1.5; x ≤ 0.5 → resist +1, +1. If 3+ weaknesses and weak > resist: −2. If any weakness and no resist (exposed, no safe switch-in): −2.
- Offensive coverage: count of types hit super-effectively by any attack option. Options are the entered moves' types, or own types (STAB) if none entered.
- Team score = defensive + 0.75 × coverage.
- Also shown: exposed types, uncovered types, physical/special balance, suggested next additions (score gain, with what each covers and hits), warning if abilities unset.
- Recommended moves (advice only): four learnable moves per member, greedy on power × STAB 1.5 × role fit (0.6 off-role) + 40 per type newly hit super-effectively; members share one coverage set so they complement each other. Self-KO, recharge and charge-up moves excluded.
**Evolve:** each Pokémon shows its vanilla evolution method(s); "Evolve → X" swaps species in place, keeping nature, moves, team slot, and ability when the evolution can have it.
**Look For tab:** species the player can realistically get, from families not owned. With hack location data (Unbound): only species with a where-to-find entry, catching the earliest stage the hack offers directly (evolve-only entries point back), shown as "Where". Without it: the vanilla rule (no legendaries, mythicals, Ultra Beasts, Paradox Pokémon, Megas, or lines whose best capture rate is under 30). Either way, anything needing a Master Ball is hidden: under 10% a throw with an Ultra Ball at 1 HP and asleep, using the hack's catch rate. Gifts, eggs and trades skip that check and say "no catch needed". Then ranked by team-score gain (current team, or auto-built six), one per family. Names the stage to search for and the evolution line to it. Catch plan: Quick Ball turn 1; a roster member with False Swipe; sleep (×2.5) or paralysis (×1.5) move, respecting type and ability immunities; best ball (Net, Fast, Dusk, Timer, Dream, Ultra) with Gen 3–4 per-throw odds as an estimate.
**Auto-build:** only Pokémon in the setup's generation; if those ≤ 6 take all; else greedy add by best marginal score, then swap hill-climb until no improvement.
**Generation rules** (setup "Pokémon up to Gen N"; Gen 9 is vanilla data unchanged):
- Pokédex and Opponent search, Look For, evolutions and catch stage capped at Gen N (no Munchlax to catch for Snorlax in Gen 3). Owned Pokémon above the cap are kept, flagged, and left out of Auto-build.
- Moves above Gen N are hidden; learnsets keep only moves learnable in a Gen N game or earlier.
- Before Gen 6: no Fairy type (17 types), Steel resists Ghost and Dark, species use their old types (Clefairy is Normal).
- Abilities as they were then (Gengar has Levitate through Gen 6); no hidden abilities before Gen 5; no abilities before Gen 3.
- Gen 3 and earlier: physical or special set by the move's type.
- Balls: Quick and Dusk from Gen 4, Dream from Gen 5, Fast in Gen 2 and Gen 4+, Timer and Net from Gen 3. Sleep is ×2 for catching before Gen 5.
- Changing a setup's generation re-derives types and abilities the player never edited.
**Opponent tab:** pick a hack trainer and tap one of its team (fills species, level, ability, item, nature, EVs, IVs, moves), or pick from the dex with optional ability, level and moves. Rank the current team (or all owned).
- Damage (`src/logic/damage.ts`): Gen 3+ stats at level (members: perfect IVs, no EVs), formula floor(floor(floor(2L/5+2)·P·A/D)/50)+2, then roll 85–100%, STAB (2 with Adaptability), type × defender ability, boosting items (Choice Band/Specs, Life Orb, Expert Belt, type items, gems; Assault Vest, Eviolite on defence), Huge/Pure Power, Technician. Shown as % of the defender's Hit Points.
- Takes = the opponent's hardest hit: its known moves (Hidden Power with a type counts), else its strongest learnable own-type move up to power 120. With unknown moves, a harder learnable coverage move is shown as a warning. Opponent level defaults to the member's own.
- Deals = the member's hardest hit with its entered moves, else a power-80 move of each own type (marked as a guess).
- One-hit-knockout risk: the top roll of takes (or coverage) reaches 100%.
- Hits to knock out: theirHits = ceil(100 / its best roll, guessed coverage included); myHits = ceil(100 / the member's worst roll).
- Survive, then win (same rule in every hack): members that deal no damage go last; then those that survive its hardest hit (or are faster and one-shot it); then those that win the exchange (faster: myHits ≤ theirHits; slower or a Speed tie: myHits < theirHits); then most theirHits (defence first); then fewest myHits; then faster (real Speed at level); then slot.
- Setup warning: if its known moves include a setup move (Dragon Dance, Swords Dance, Nasty Plot and the like) and the member needs three or more hits, say so. Warning only; it doesn't change the order.
- Output: best and worst member with "Takes 38–45% (Earthquake)", "Deals 60–71% (Surf)", the type sentences ("Ground STAB deals double damage (×2) to Gengar", "via Levitate"), and speed. Learning tip: a learnable move (power ≥ 60) whose top roll beats the current best by 1.2×. Full order line (takes N% or KO · deals M%). Party bar marks each slot with damage taken. "Currently out" picker: best move, knockout warning, rank, and whether to switch.

## 6. UI requirements
- Mobile-first, light and dark themes, safe-area padding.
- Four tabs: Pokédex (checklist), Best Team (analysis and moves), Look For, Opponent. The Dex header and party bar stay pinned while the screen scrolls.
- Editor (in the Pokémon modal): ability, level and nature up front; types, moves and base stats under a collapsed "Hack changes" section; Remove needs a second tap.
- Custom suggestion list (not native datalist, which covers the keyboard): up to 6 buttons directly under the input, prefix matches first, selection on pointerdown, input scrolled towards the top on focus, extra bottom padding so the page can scroll.
- Warnings in red.

## 7. Known limitations
- Damage is an estimate: no critical hits, weather, terrain, stat stages, burns, screens, multi-hit or variable-power moves; Gen 1–2 use the Gen 3 stat formula; only the items and attacker abilities listed in section 5.
- Best Team scoring is still type-based; it does not yet score against a chosen boss team.
- Hack packs: Unbound and Emerald Rogue only. Sources for Radical Red, R.O.W.E., Inclement Emerald, Renegade Platinum and Crystal Clear are known (romhackdex.net's credits list) but not parsed. Unbound's TM/tutor compatibility isn't in its source, so learnsets are vanilla plus its level-up moves. Unbound's Vanilla difficulty uses the Difficult teams. Boss levels come from the trainer docs; if the game scales them, edit Level. Setup moves are a warning, not simulated. Catch odds use normal balls; if Unbound applies the Ultra Beast penalty (only Beast Balls work well), odds shown for Ultra Beasts are too high. The checklist renders every row (about 500–1,100); window it if a phone lags.
- No share links or file export/import.
- Generation rules not modelled: Gen 1 type-chart quirks, move power changes between generations, Gen 6/7 base-stat buffs (stat overrides cover these), and abilities introduced after the cap still appear in the free-text ability list. A hack with Gen 6+ Pokémon but no Fairy type can't be expressed.
- Sync is last-write-wins per setup; two people editing the same setup at once would overwrite each other.
- Tested with unit tests and a Playwright smoke test in Chromium at phone size, not yet on a real phone.

## 8. Suggested build plan
1. **Project:** TypeScript + Vite static site; pure logic modules (typeChart, abilities, scoring, opponent) separated from UI.
2. **Data script:** reproducible PokeAPI → JSON generator; commit outputs with a version stamp.
3. **Tests:** unit tests for the type chart, ability effects, scoring formulas, auto-build determinism, stat editing.
4. **Port prototype behaviour** (acceptance: matches section 5).
5. **Backlog:** score Best Team against a boss team; more hack packs; JSON export/import and share URL; more abilities; real-device mobile testing; accessibility pass.
6. **Done:** multiple game setups with server sync (Node, JSON files in a volume; no accounts, optional access code).
**Risks:** hack data differs from vanilla; fan-project IP (Pokémon is Nintendo's); do not distribute ROM data; attribute PokeAPI. Scoring weights are heuristic and need user feedback.
**Success criteria:** works offline-capable on mobile, correct on known type matchups, an explanation shown for every ranking.
